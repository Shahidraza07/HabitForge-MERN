# 🔥 HabitForge - MERN Stack Habit Tracker

HabitForge is a full-stack web application designed to help users track their daily habits, optimize routines, and maintain a secure optimization tracking terminal dashboard. This project was developed as part of the **Persevex Web Development Internship (Project 1)**.

## 🚀 Live Deployment Links
- **Frontend (Live Website):** https://vercel.com/shahid-raza-s-projects/habit-forge-mern/6scMMqyu7Hb2ueFiGQMenMSqqv82
- **Backend API (Render Live):** https://dashboard.render.com/web/srv-d89s62ojo6nc73e4rt40/events

## ✨ Key Features
- **Secure Authentication:** User signup and login system using JWT and password encryption.
- **Interactive Dashboard:** Complete tracking terminal showing user progress and level metrics.
- **Matrix Breakdown:** Visual representation of habit success rates and activity charts.
- **Responsive UI:** Tailored layout optimized for desktop, tablet, and mobile viewing.

## 🛠️ Tech Stack Used
- **Frontend:** React.js, Vite, Tailwind CSS, Component UI Libraries.
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas (Cloud Database)
- **Deployment:** Vercel (Frontend) & Render (Backend)

## 📁 Project Structure
- `/client` - Frontend codebase (React + Vite)
- `/server` - Backend API codebase (Node + Express)
